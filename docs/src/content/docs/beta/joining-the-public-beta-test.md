title: Joining the Public Beta Test
description: Learn how to join the public beta test for Peptide for Android.

---

The public beta test for Peptide for Android is available to anyone with an Android device
in [those jurisdictions](https://peptidechat.github.io/android/beta/availability-regions/) where the
beta test is available. The beta test is open to everyone, and you can join the beta test by
following these steps:

1. [Join the Peptide for Android Alpha Track on Google Groups](https://groups.google.com/g/peptide-android-alpha-track).
2. [Opt-in to the Peptide for Android Beta Test on Google Play](https://play.google.com/apps/testing/chat.peptide).
3. [Download Peptide for Android from Google Play](https://play.google.com/store/apps/details?id=chat.peptide).

You're all set! You can now use Peptide on Android and help us test new features and improvements.

If you encounter any issues or have any feedback, please let us know
by [reporting an issue](https://androidtasks.starlightjen.com/)
or [joining the Peptide Developers server](https://rvlt.gg/api).
